# UI 與 UX：以內容、操作結果及當下任務為中心

狀態：設計提案。這次依原始碼分析資訊架構與操作流程，沒有執行實際介面測試或使用者訪談；以下可用性判斷須在實作後驗證。這是規格文件，不新增可執行 UI 預覽。

## 1. 統一介面骨架

兩個工作台沿用相同操作語言，保留各自領域入口。

| 區域 | MD 管理台 | 理解工作台 |
|---|---|---|
| 頂列 | 專案／來源範圍、搜尋、工作進度 | 專案、當下任務版本、搜尋、脈絡用量 |
| 左導覽 | 文件、整理建議、變更計畫、歷史 | 當下任務、知識、視覺資料、學習回報、歷史 |
| 主區 | 清單、閱讀／編輯、變更比較 | 任務摘要、知識清單、素材與實作比較 |
| 右側詳情 | 路徑、狀態、來源、引用、選取原因 | 適用條件、來源、驗證、失效原因 |
| 共用活動中心 | 處理中、成功、部分成功、失敗、可復原項目 | 同左，增加本次 AI 讀取紀錄 |

頂列切換範圍後，清單、檢索、選取及資料修改使用同一個範圍版本。右側面板預設收合；重要內容不要同時擠進三個窄欄。選取後在清單上方出現固定批次操作列，捲動時仍可看到影響數量。

1280 px 以上可使用導覽＋主區＋選用詳情面板；較窄時先收合詳情，再將導覽改成抽屜。小螢幕編輯時讓文件占滿主要空間，左右差異改為上下比較。寬度只是初始斷點，應以內容溢出測試調整。

## 2. 藍黑白色系與可讀性

以藍黑色作為應用外框、白色作為主要文字；長篇閱讀／編輯區預設提供白紙面。使用者可切換深色閱讀，兩種模式使用同一版面與功能，不再分出功能不同的「精簡版」。

| Token | 色碼 | 用途 |
|---|---|---|
| background | #080F1E | 應用背景 |
| surface | #111D33 | 面板、表格、導覽 |
| elevated | #172640 | 浮層、選取區背景 |
| foreground | #F5F8FF | 深底主要文字 |
| secondary | #B7C7E2 | 說明、次要資訊 |
| primary | #2463EB | 主要動作、主導覽選取 |
| control-border | #647B9E | 輸入框、可操作元件邊界 |
| separator | #31435F | 非必要裝飾分隔線，不用來單獨辨識控制項 |
| focus | #9DD1FF | 鍵盤焦點 |
| paper | #F8FAFC | 長篇閱讀、文件編輯區 |
| ink | #14233B | 白底文件文字 |

依 WCAG 相對亮度公式計算，指定實色組合的對比分別為：

| 文字／元件與背景 | 對比 |
|---|---:|
| foreground / surface | 15.84:1 |
| secondary / surface | 9.85:1 |
| foreground / primary | 4.87:1 |
| control-border / surface | 3.90:1 |
| focus / surface | 10.42:1 |
| ink / paper | 15.05:1 |

一般文字以至少 4.5:1、大字至少 3:1 為基準。上述數值不涵蓋透明度、漸層、hover 或 disabled 狀態，實作時須逐一驗證；不能用色票合格代替整頁檢查。[WCAG 文字對比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)

設計限制：

- 不在長文、表格或編輯區使用光暈、透明玻璃背景、霓虹漸層；科技感由精確間距、穩定層次、細緻邊界及少量藍色建立。
- 正文初始 16 px、行高約 1.6；工具列與表格至少 14 px。路徑採等寬字並可展開，不用極小字塞滿畫面。
- 成功／警告／錯誤一定有圖示和文字。危險操作可用少量獨立警示色，不能為維持三色而犧牲辨識。
- 焦點環清楚且不被固定列遮住；產品點擊目標以 44 px 為設計目標，表格密度可選，但不縮小核取方塊的實際點擊區。
- 尊重減少動態效果設定。主要內容不依賴 hover 才能出現；200% 縮放後仍能讀取與操作。

## 3. 文件清單與大量選取

現有 50／100／200 筆、跳頁、跨頁選取及最多 2,000 筆篩選選取已有作用，應延伸一致性，不再把它描述為「只能逐頁選一個」。

新規格：

1. 全部主要清單使用相同的每頁筆數、首頁／上一頁／下一頁／末頁、頁碼跳轉及總量／估計量標示。
2. 支援 Shift 範圍選取、鍵盤移動與選取、選取本頁、選取全部符合篩選的結果。
3. 大量「選取全部」以伺服器選取快照表示：範圍、查詢、索引版本、排除 ID 與精確件數；不要為選取而把每份文件內容載入瀏覽器或 AI。
4. 篩選改變後明確顯示「目前篩選中 28 份、其他篩選中 12 份」。提供「取消目前篩選內的選取」與「取消全部選取」，不要使用「清除」。
5. 根目錄改變或資料版本改變，不默默套用舊選取。保留可檢視快照，重新驗證後才執行修改。
6. 批次作業顯示可執行、略過、衝突件數。先產生變更計畫，再按授權範圍套用；大型作業可取消後續批次，已完成項目列出還原入口。

預設列只顯示名稱、用途／分類、狀態、最近有效變更、建議數；完整路徑、hash、內部 ID 放在詳情。已手動確認的分類與 AI 推測分類有文字標記，不能混為同一個確定結果。

## 4. 閱讀、編輯與比較

閱讀區先呈現安全的 Markdown 排版，原始碼是可切換模式。編輯區支援語法上色、段落目錄、文件內搜尋、行號、連結定位及預覽；原始 HTML 預設不執行，外部內容不能注入操作指令。

保存行為：

- 顯示「未儲存／草稿已保留／已儲存／來源已變更」，並區分本機草稿與原文件寫入。
- 草稿以專案、文件 ID、基準 hash 與使用者工作階段保存，重開可恢復；提供草稿保留期限及清除控制。
- 儲存前比對原文件版本；發生衝突進入基準／本地／目前版本三方比較，不靜默覆蓋。
- 保留 BOM、換行與不相關 frontmatter 欄位。格式化與內容修改分開展示，減少無意義差異。
- AI 修改先定位段落及列出差異、理由、來源；使用者能接受部分修改或排除個別段落。

拆分與合併使用雙欄：左側來源段落、右側新結構。未搬移的有效條款、例外及失效連結保持可見；不要只展示新的漂亮摘要。

## 5. 理解工作台的主要畫面

### 當下任務

最上方顯示目標、交付物、限制、驗收與尚待確認的假設，每項可回到原始需求。下方只顯示本次已選用知識，附「為何相關」「適用版本」「驗證程度」「預估讀取量」。

提供「需要才讀」「本次排除」「固定為本次依據」三種操作。固定依據仍受失效與版本檢查；固定不是永久指令。更換任務版本後重新檢查，避免上一個任務的偏好污染下一個任務。

### 知識資料庫

預設按任務相關性排序；其他視圖為待驗證、衝突、過期、待整合及封存。每份知識先顯示一句用途、適用條件與證據；編輯時才展開完整欄位。

領域資料包可加入、修訂與停用。包內入口短而清楚，細節以附件載入；「安裝一包」不等於每次把整包傳給 AI。

### 視覺資料

參考、解構、實作、比較四個工作區共用同一素材 ID。靜態圖提供區域框選與標記，動態資料提供時間軸與狀態。比較畫面同步縮放、視窗尺寸及選定區域，差異說明連到實作與證據，不只列美觀分數。

## 6. 操作回饋契約

所有按鈕都必須得到可觀察結果，包括沒有變更或只完成部分的情況。Toast 只是提示，完整紀錄進活動中心。

| 狀態 | 建議文字 | 必要操作 |
|---|---|---|
| 進行中 | 正在索引：已處理 320／900 份 | 顯示階段；可取消時提供取消 |
| 成功 | 已更新 12 份文件的分類 | 查看明細、可用時復原 |
| 無變更 | 12 份文件已是此分類，未變更內容 | 返回清單 |
| 部分成功 | 已更新 10 份，2 份因來源變更略過 | 檢視衝突、只重試失敗項目 |
| 無結果 | 此範圍沒有符合條件的知識 | 顯示篩選條件、調整搜尋 |
| 失敗 | 儲存未完成：原文件已有新版本 | 開啟比較、保留草稿 |
| 已取消 | 已停止後續處理；完成 20 份，未處理 80 份 | 查看已完成、復原 |
| 權限不足 | 此動作超出目前授權的目錄／動作 | 顯示具體範圍及必要的授權入口 |

錯誤使用持續可見的區塊；正常提示可自動消失。避免只寫「完成」「失敗」而不知道哪個工作受到影響。非同步更新使用適當的輔助技術宣告，不能搶走正在輸入的焦點。

## 7. 必測操作情境

- 在第 8 頁選取、修改篩選、重新命名後，選取件數與操作目標仍正確。
- 編輯未儲存時切換任務、重新整理、來源被外部修改，草稿可找回且不覆寫新內容。
- 同時開兩個工作台，分類與標記操作有原子性；一部分失敗時結果可辨識。
- 大量工作可追蹤進度，重開介面後能找回作業；沒有永遠停在「忙碌中」的按鈕。
- 長中文檔名、長英文路徑、無內容、萬筆資料、200% 縮放及純鍵盤操作可完成核心流程。
- 看不到色彩差異時，仍能辨識目前選取、待刪除、失效、錯誤與驗證程度。

驗收不能只問「是否更好看」。至少觀察使用者找到一份文件、跨頁整理、處理儲存衝突、理解本次 AI 用料四個任務的完成率、時間、誤操作及回頭尋找次數。
