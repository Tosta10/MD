# 理解工作台與 MD 管理台：v2 企畫入口

本文件保存 v2 設計與介面示意；後續已開始交付本機 v2，實際支援與後置項目見 [實作進度](../../實作進度.md)。以下功能與門檻仍為規劃，不代表全部已實作或已量測。延續原有名稱，兩個插件可獨立使用，共用來源、版本、證據與變更底層。

## 依需要讀取

| 目前要處理的事 | 讀取文件 | 能得到什麼 |
|---|---|---|
| 理解需求、領域專業、經驗取用與學習成果 | [理解工作台企畫](insight-plan.md) | 任務與知識模型、按需檢索、成果回報、維護工具、驗收及分期 |
| MD 整理品質、效能、批次操作與 UI | [MD 管理台企畫](md-manager-plan.md) | 現況問題、增量索引、五原則升級、合併刪除、介面與效能驗收 |
| 要實作資料庫或 MCP API | [共用資料與工具契約](references/contracts.md) | 權威資料位置、欄位、狀態、版本衝突、回傳預算及變更協定 |
| 要核對論據或 Thariq 方法的來源 | [現況與來源](references/baseline-and-sources.md) | 程式位置、方法對照、原始來源與未獨立核實項目 |
| 要使用實際介面 | [使用說明](../../README.md) | 開啟正式工作台；離線 UI 示意已移除 |

AI 先按任務選擇一份主企畫，只在需要欄位或證據時讀取附件。詳細資料有固定 ID 與版本，避免把所有規劃、知識與歷史一次載入。

## 建議先實作的決策

1. 先補正確性：有效狀態統一、掃描失敗保留索引、經驗修訂後重驗、可還原刪除。
2. 再控制讀取成本：有限搜尋、摘要後詳讀、分頁 API、移除全量 refresh 與健康檢查中的分析。
3. 建立增量索引與新工作區，再導入相似群組與 AI 語意審核。
4. 向量檢索、外部模型及多人雲端協作後置；首版升級保持本機可用。

Thariq 的八種方法採按需選用；「精簡提示、豐富成果、精簡 skill」落實為可尋址的資料與工具，而非增加一份每次必讀的長指令。查核範圍與來源見附件。
