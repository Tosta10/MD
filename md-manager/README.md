# MD 管理台 v2

盤點與分類指定範圍內的 Markdown，依五項原則提出候選問題，提供整合、差異與可還原變更。

v2 加入增量索引/進度/取消、服務期間監看、跨頁選取、章節讀取及編輯、移動改名與引用修復、近似候選及審核狀態。字詞相似不是可刪除判決；語意合併由 Codex 或使用者核對。回收與修復頁可還原來源，沒有自動永久清除。

雙擊「開啟工作台.cmd」使用本機介面；在 Codex 安裝本機插件後，可使用 `$md-manager` 或請它呼叫 `open_workbench`。

完成文件可以標成「待刪除」，保留理由、完成依據、取代文件、確認狀態與原始雜湊。標註不修改原文或直接刪除；完成且確認後才可建立刪除方案。套用前檢查版本與已索引引用，原文可透過批次還原。

需要 Node.js 24+；啟動器會尋找 Codex 捆綁 Node 或 CODEX_NODE_PATH。資料預設保存在使用者家目錄 `.codex-md-workbenches`，可用 CODEX_WORKBENCH_HOME 指定，避免放在安裝快取內。

主資料庫為 workbench-v2.sqlite。首次啟動會從既有 workbench.sqlite 建立一致快照，保留舊庫；切換後請使用 v2，舊服務快照後的新寫入不會自動合併。Codex 插件需從本機來源更新並在新對話載入；build 不修改安裝快取。

五原則檢查提供可解釋候選；語意合併由 Codex 或使用者判讀。授權、套件與硬連結來源只提供建議。相同資料可和理解工作台交換任務情境，不擴張讀寫權限。
