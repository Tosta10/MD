# 四領域遞增難度對照報告

日期：2026-10-27。四類皆分插件組與不載入插件的自訂 Node.js 對照組，每組從小規模逐級增加，到不符合判定或到預設測試上限為止。資料為隔離的合成資料，沒有執行模型推理。原始逐級紀錄在 raw/progressive-comparison.json；修復前紀錄在 raw/progressive-comparison-before.json。

| 類別／遞增方式 | 插件組結果 | 無插件對照結果 |
|---|---|---|
| 需求保存：輸入文字長度 | 10,001個重複字加前綴可完整保存；14,001個加前綴因超過14,000字上限明確拒絕 | 到14,001個加前綴仍通過，達測試上限；沒有測得失敗點 |
| 知識檢索：逐級增加干擾知識 | 逐級加入1、20、60、130、250筆干擾後仍能取回目標；達測試上限 | 自訂精確字串搜尋各級皆通過，達測試上限；沒有測得失敗點 |
| 視覺資料：同一紀錄的素材數 | 1、5、10、20張通過；21張超過現有20項上限而拒絕 | 同數量JSON識別碼皆通過至21，達測試上限；沒有測得失敗點 |
| 來源保存：文字長度 | 100、1,000、10,000、40,000個重複字加標題通過；64,001個加標題超過64,000字上限被拒絕 | 相同文字分段至64,001個加標題仍通過，達測試上限；沒有測得失敗點 |

上述上限是受測 API 的資料限制，不能直接解釋成 AI 任務能力的失敗。干擾資料在同一測試庫中逐級累加；無插件組只實作測試需要的字串搜尋及JSON資料結構，未實作範圍權限、版本、來源追蹤、圖片儲存與其他插件功能，故不是功能等價的產品比較。視覺題驗證資料保存，不代表看圖、畫面還原或審美。沒有測量耗時或 token。

## 測試發現與修正

修復前插件組在10,001個重複字的需求保存測試中出現靜默截斷；已改為保留最多14,000字的完整原文與前後空白，超限時明確回報。重跑後該級通過，超限級明確拒絕；另新增回歸測試。視覺參考新增刪除確認、回收與還原，保留共享檔案並以版本檢查防止過時操作。

## 驗證與不足

71項程式及整合測試通過；瀏覽器實測刪除彈窗、取消、確認移入回收區、還原。無插件組和知識檢索兩組都達預設最大測試級別而尚未失敗，因此並未滿足所有組別「直到失敗」的條件；沒有將測試上限冒充失敗。要找到真正失敗點需擴大測試資源與規模，並另設合理的時間、記憶體停止條件。

本次並非有／無插件的 AI 能力盲測，不能據此判定模型的視覺、解題或理解能力提升。真實比較需同一模型、相同素材與各組隔離環境，逐級執行實際任務並以預先定義的驗收條件評分。
