# MD 管理台與理解工作台 v3

> **開始使用：** [醒目使用手冊／安裝外掛／適用模型](使用手冊.md) · [完整測試與實際成效](docs/verification/完整測試與成效報告.md)
> 工作台頁首也有「使用手冊」及「測試與成效」入口，可快速查閱及列印。

本機 Markdown、任務知識與視覺實作工作台。包含兩個可獨立安裝的 Skills＋MCP 插件，以及共用網頁介面。AI 由目前宿主提供；網頁本身不偷偷呼叫模型或上傳資料。

## 開啟與升級

雙擊「開啟工作台.cmd」，或各插件資料夾內同名檔案。Windows 啟動器會核對版本及資料目錄，需要 Node.js 24+。

Codex 本機來源清單是 .agents/plugins/marketplace.json。建置後，從本機來源更新／重新安裝 md-manager、insight-workbench，再開新對話使用；已開對話的工具列表不會自動換版，安裝快取不直接改寫。

其他 MCP 宿主可參考各包的 mcp.portable.json，將 PLUGIN_ROOT 替換為插件絕對路徑並使用 Node.js 24+。Windows 已測；其他作業系統仍需各自驗證。沒有 MCP 的聊天介面可以使用匯出的有限 JSON／MD 資料，但不會自動回寫。

首次到「管理範圍」加入明確資料夾，再索引。原 MD 保留原位置；個人 skills 要另外加入，不自動掃其他磁碟或歷史對話。

## MD 管理

- 增量索引、可觀察作業、服務期間監看；暖掃描不重讀未變正文。
- 50／100／200筆、前後／末頁／跳頁、跨頁選取。超過2,000筆可固定最多50,000筆選取快照，背景分批標記，列出衝突與部分結果。
- 五原則候選與有來源的AI語意審核：用途／觸發、路由附件、責任／測試映射、前提式授權、重疊／衝突。
- 安全 Markdown 閱讀、表格、原始碼、章節與全文編輯；本機草稿有版本，重開可恢復。
- 字面搜尋取代、純量 frontmatter 編輯、路由器＋附件、移動／改名及引用修復，皆先產生方案。
- 整合2–8份時鎖定每份來源。原文未保留的內容區塊，必須逐條記錄取代位置或捨棄理由；後端覆蓋檢查不能由UI表單繞過。
- 標註與分類原子保存；完成、待刪除、回收及永久刪除分清。保留還原與後續衝突檢查，沒有自動永久清除。

規則與字詞相似只產生候選。相似分析有配對及候選文件上限，truncated表示未完成全量比較；不以相似、低頻或日期舊直接刪除。支援標準Markdown相對引用，Wiki／HTML／外部系統引用及完整anchor校驗不在保證內。授權、受管、硬連結來源受保護。單份MD最多2MiB，非UTF-8保留並回報。

## 理解與研究資料庫

「本次任務」保存原始需求、目標、限制、交付、驗收、未知、假設及環境。原文與歷史版本保留；提示詞優化是有來源的任務表示，不新增使用者目標或權限。

「當下脈絡」按目前任務版本選取少量適用資料，顯示選用理由、來源與未確認項。新加入知識不會每次全部閱讀。

研究來源保存URI、日期、作者、使用權、hash、摘要／獲授權內容及觀察／推論。由宿主AI搜尋後透過工具存入，工作台不自行爬網。來源修改或封存會使依賴知識需複查。

檢索先做專案、生命週期、有效期及環境篩選，再融合中文詞片、關鍵字及FTS5排名。版本可用比較範圍、^／~；未解析條件留作不確定。支援宿主提供向量的本機融合，綁定模型／維度／知識版本；沒有自動embedding或外部服務費用。

知識預設候選。可靠程度與保留狀態分開，修訂要expectedRevision；來源或實質內容改變需重新核對。領域包有薄入口、版本及陷阱；JSON資料包可分批匯出入，匯入提出候選方案。

## 靜態與動態視覺

素材單份8MiB；PNG／JPEG最多1600萬像素。保存來源、hash、尺寸及範圍；同二進位可共用儲存。PNG／JPEG由有上限工作器做局部裁切、縮圖及像素比較。WebP由介面轉PNG後可裁切；未轉換的WebP不能假裝已有受控裁切。

MP4／WebM可保存；瀏覽器支援解碼且60秒內的影片可擷取6個取樣影格及時間軸。AI按需讀影格，插件不把完整影片當圖片輸入；此版不內建伺服器影片解碼器。

四類視覺紀錄：

| 類型 | 保存內容 |
|---|---|
| 區域解構 | 可見觀察、實作假設、限制、區域及位置 |
| 效果配方 | 技術棧、渲染／布局方法、參數、陷阱、實作與驗證位置 |
| 時間軸 | 影格、時間、狀態、觸發及轉場 |
| 成果評價 | 實作、環境、多維評價、改善與證據 |

AI可透過同一組工具建立紀錄；介面的「複製AI分析任務」產生可貼回已連接AI的任務，不冒充按下即有模型自動執行。實作在宿主既有開發工具中進行，再匯入實際產物與證據。

本機像素相似度是量測，不代表審美或功能通過。單圖不能證明原作者程式、動態、隱藏狀態或效能。

## 自主整理與操作回饋

政策明列範圍、動作、額度、有效期及理由。符合政策後可套用已完成的具體方案；依然檢查hash、revision、覆蓋及保護條件。明示過期或同來源同條件的完全重複候選可以依政策封存，其他情況保留審核。

政策額度在執行前保留，失敗嘗試也占用額度。保留期目前用於紀錄，不會觸發永久清除。沒有關閉後仍運行的排程。

所有主要操作提供成功、無變更、部分完成或失敗回饋；操作紀錄可查回，不只依賴短暫提示。UI與AI共用版本、交易、來源及復原服務。

## Token與效果

MCP預設只揭露常用工具。get_workbench_capabilities按需載入documents、jobs、governance、knowledge、research、tasks、visual群組，發送標準tools/list_changed通知。不支援工具列表更新的宿主可設定WORKBENCH_TOOL_PROFILE=all，重新連線後使用完整工具。


context_run共用文字、圖片及bytes預算；未提供runId仍有預設帳本。一般材料目標約1500–3000額外文字tokens，預設run上限6000估計tokens、48KiB及3張圖，可明確設定。

圖片採像素啟發式估計，文字也不是指定模型tokenizer。宿主歷史、工具定義、推理與輸出另計；可由宿主回報實際用量。讀取按版本去重、查詢快取含索引世代。已開始操作的精簡完成回條可超過最後剩餘量，下一項操作前再檢查預算。

A/B/C評測可保存同模型、設定、資料集、保留題、證據及用量；沒有資料就回not_measured。功能測試和檢索改善不等於已證明跨領域AI品質顯著提升。

## 資料及相容

預設為使用者家目錄下 .codex-md-workbenches，也可用 CODEX_WORKBENCH_HOME 指定。兩插件同目錄才共用資料。

- workbench.sqlite：保留的舊版庫。
- workbench-v2.sqlite：保留的v2庫。
- workbench-v3.sqlite：v3主庫，從v2一致快照升級。
- before-v3.sqlite：首次新增v3結構前的快照。
- assets/：主動匯入的素材。

舊服務仍可讀寫舊庫；切換後請使用v3，舊庫之後的新寫入不自動合併。升級不重設原資料。回復舊程式前保留新庫及資產，不能以刪除新庫模擬完整回滾。

## 建置與測試

~~~powershell
pnpm install --frozen-lockfile
node scripts/build.mjs
node --test tests/*.test.mjs
powershell -NoProfile -File scripts/Package-Plugins.ps1
~~~

介面測試使用Playwright及Edge：設定WORKBENCH_PLAYWRIGHT_ROOT為含Playwright的node_modules，執行tests/ui-usability.mjs、tests/v2-browser.mjs、tests/v3-browser.mjs及tests/large-selection-browser.mjs。影片驗證另設定WORKBENCH_VIDEO_FIXTURE為明確的本機WebM測試檔。產物在artifacts/，使用者資料、測試暫存及壓縮包不進Git。
